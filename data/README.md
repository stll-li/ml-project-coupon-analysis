# Data Description

The datasets used in this project are derived from **real-world business data provided by Meituan**, one of the largest on-demand service platforms in China, offering services such as food delivery, local lifestyle services, and digital commerce.

Due to data privacy regulations and business confidentiality requirements, the original raw dataset **cannot be publicly released**. The files included in this repository have therefore been **fully anonymized and processed**, ensuring that no personally identifiable information or sensitive business data is disclosed.

## Included Files

### `train.xlsx`
- The processed training dataset used for model development.
- Contains cleaned and feature-engineered variables derived from the original dataset.
- All sensitive fields have been removed or anonymized.
- Suitable for reproducing the training and evaluation pipeline in this project.

### `predict.xlsx`
- A sample dataset used for model inference and demonstration of the prediction pipeline.
- Structure and feature format are consistent with the training data.
- Used to generate predicted outcomes using trained models.

## Notes
- The data is provided **strictly for academic and demonstration purposes**.
- Any commercial use or attempt to reverse-engineer sensitive information is prohibited.
- The dataset structure is designed to support reproducibility of the modeling workflow presented in this repository.
